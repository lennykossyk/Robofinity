# Robofinity

Modular robotics chassis system — Gridfinity floor + DIN rail walls + M3 heat set inserts.

**Live site:** https://lennykossyk.github.io/robofinity

## Built with

- [Three.js r128](https://threejs.org) — STL viewer
- [Gridfinity standard](https://gridfinity.xyz) — base grid system
- Part of the [ORCA](https://github.com) robot platform
